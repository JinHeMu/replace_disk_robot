# 加长硬盘仓与摩擦验证

日期：2026-09-10。本次修改场景与接触验证，不改动现有 Servo、键盘控制或导纳算法。

## 几何与接触方式

- 四壁仓体由 40 mm 加长至 **190 mm**，超过硬盘的 177 mm 长度，形成包覆式直通仓。仍无后挡板、无连接器模型。
- 硬盘仍为 177 × 106 × 26 mm，入口结构净尺寸仍为 106.5 × 26.5 mm。原有每侧 0.25 mm 间隙仅指硬质外壳，不代表导轨处无接触。
- 两侧仓壁内增加圆头弹性摩擦导轨，圆柱半径 1.2 mm，轴线从入口后 12 mm 延伸至 178 mm，圆头最前端位于入口后 10.8 mm。
- 导轨未受载时两内表面间距 **105.96 mm**，相对 106 mm 宽的硬盘，每侧有 0.02 mm 预压配合量。进入后导轨向外让位，产生真实的法向接触载荷。
- 每条导轨设置被动滑动关节：刚度 12400 N/m，弹簧参考位置 −0.5 mm，阻尼 24.8 N·s/m，质量 0.124 kg，向外行程 0–2 mm，重力补偿。按理想居中位移估计，每侧法向预紧力约 6.45 N。
- 导轨滑动摩擦系数 **0.6**，采用三维接触约束（法向与两切向）；高优先级确保实际接触使用导轨参数。仅排除导轨安装处与仓壁的重叠，硬盘—仓壁、硬盘—导轨、夹爪—仓体碰撞保留。

这是一种弹性内衬/压紧导轨的等效仿真，并非实测材料模型。推进阻力来自接触摩擦，不是人为给机械臂叠加恒定反力。MuJoCo 参数含义参考[官方 XML 文档](https://mujoco.readthedocs.io/en/latest/XMLreference.html)。

初始位置仍在入口外 10 mm，无硬盘接触。仓体可以容纳硬盘的长度，但当前刚性夹持和目标插深保持原有定义，不能据此宣称已实现整盘完全送入或自动松爪。

## 运行

在仓库根目录、激活仓库隔离环境后：

```bash
python examples/scene_display_exp.py
python examples/validate_insertion_friction.py
python examples/validate_insertion_contact.py --output simulation/mujoco/reports/contact_validation.json
python -m pytest -q
MUJOCO_GL=egl python examples/capture_scene.py
```

`validate_insertion_friction.py` 会自动运行带摩擦推进/回退、减半时间步、零摩擦对照，并检查滑动载荷为 **7.5 ± 0.5 N**，输出 `simulation/mujoco/reports/friction_validation.json`。它是有 15 N / 2 N·m 上限的位置驱动标定夹具验证（仅此验证入口；原 Servo 的 10 N / 1 N·m 限制保持不变），**不是闭环力控插入控制器**。

现有键盘 Servo 的无碰撞门仍会阻止主动进入接触；本次不放宽它。检验摩擦请运行上面的独立验证入口，后续接触控制需显式区分允许的硬盘接触和禁止的机械臂碰撞。

## 原低阻力版本结果（历史记录）

以下表格对应调到 7.5 N 之前的低预紧版本；不可作为当前场景的力值。原版完整回归 85 项通过。

| 工况 | 步长 | 推进轴向传感器均值 | 回退轴向传感器均值 | 最大穿透 |
|---|---:|---:|---:|---:|
| 摩擦系数 0.6 | 1 ms | +0.543 N | −0.541 N | 0.0449 mm |
| 摩擦系数 0.6 | 0.5 ms | +0.586 N | −0.583 N | 0.0202 mm |
| 零摩擦对照 | 1 ms | −0.065 N | +0.064 N | 0.0432 mm |

世界坐标 +X 为插入方向，腕部报告父体对子体的载荷；推进时传感器 +X 与环境对硬盘的阻力方向相反。零摩擦时传感器仍有运动惯性项，因此另行检查接触反力：零摩擦轴向接触反力接近零，有摩擦时约 0.606 N。记录中的传感器值与接触力均值存在约 0.06 N 的运动载荷差。

减半步长的推进/回退载荷差约 0.043 N，最大穿透低于 0.05 mm；这不等同于瞬态完全收敛或实机标定。验证中只有硬盘—导轨接触，推进到约 60 mm 后回退至约 30 mm。

几何路径测试将导轨设置在可达的受载外移位置，仅检查机械臂/夹爪与仓体的几何兼容性。实际预紧、摩擦和运动由独立动态测试覆盖，不能再要求正常插入时完全无接触。

## 调参位置

实际参数在 `simulation/mujoco/scene.xml`：

- `socket_liner_left/right` 的 `friction` 控制摩擦强度。
- `socket_liner_left/right_slide` 的 `stiffness`、`springref` 控制压紧载荷；增大负参考位置的绝对值可增大预紧。
- 导轨 body 的 Y 位置控制预压配合量，不应靠增加刚性穿透来追求更大阻力。

`config/task_sequence.yaml` 是参数说明，不是运行时场景生成器。每次改变摩擦或预紧后都应重跑对照验证，检查载荷、穿透和步长敏感性。

## 按实测 7.5 N 标定的当前版本

用户提供实际插入约需 7.5 N。本模型将其解释为**对正低速插入时的持续轴向阻力**，并未把静止力、首次进入导轨的峰值或全行程最大力设为恒定 7.5 N。

保持摩擦系数 0.6、开口和导轨位置不变，将导轨弹簧刚度由 1000 提高至 12400 N/m，同时将等效运动质量与阻尼提高至 0.124 kg、24.8 N·s/m。弹簧参考位置仍为 −0.5 mm。质量是等效内衬机构参数，不能理解为实物材料称重结果。单个推力测量不能唯一辨识真实摩擦系数和预紧力。

默认仿真步长由 1 ms 改为 **0.5 ms**，专项验证再使用 **0.25 ms** 复核。标定夹具采用平滑位置轨迹：70 mm 推进用时 21 s，30 mm 回退用时 9 s，名义平均速度 3.33 mm/s、最大约 5 mm/s。滑动均值采样在各段 40%–80% 时间区间、实际插深大于 25 mm 时进行。

为抑制负载下姿态偏差，**仅标定夹具**的机械臂位置增益为模型值的 4 倍、速度阻尼为 2 倍；不修改场景机械臂参数、键盘 Servo 或导纳控制器，不注入虚拟恒力。后续控制器仍需独立验证带载跟踪，不能将夹具跟踪能力当作 Servo 的验收结果。

当前验证报告见 `simulation/mujoco/reports/friction_validation.json`，包括目标均值、标准差、峰值力/力矩、穿透、零摩擦对照与步长比较。持续推进约 7.5 N，进入和换向的瞬时力可能更高；原 Servo 的 10 N 门仍可能触发，不能通过提高它来宣称问题已解决。
