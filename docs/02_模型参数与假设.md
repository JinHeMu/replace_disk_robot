# 模型参数与假设

## 几何与坐标

| 参数 | 值 |
|---|---|
| 硬盘完整尺寸 X/Y/Z | 0.177 / 0.106 / 0.026 m |
| 硬盘质量 | 0.20 kg，均匀长方体假设 |
| 硬盘中心初始世界坐标 | (0.55, 0, 0.45) m |
| 插口入口世界坐标 | (0.6485, 0, 0.45) m |
| 净口 Y/Z | 0.1065 / 0.0265 m |
| 通道长度 X | 0.040 m |
| 壁厚 | 0.012 m |
| 初始前端间距 | 0.010 m |
| 未来目标插深 | 0.050 m，按前端超过入口的距离计算 |

`socket_entry`、`drive_center`、`drive_front` 的初始坐标轴与世界系一致：X 插入、Y 宽度、Z 厚度且向上。两个参考点位于硬盘中心和前端中心。四元数为 wxyz，所有模型长度使用米。

惯量由 MuJoCo 根据盒体尺寸和 0.20 kg 质量计算：Ixx=m(W²+H²)/12，Iyy=m(L²+H²)/12，Izz=m(L²+W²)/12。硬盘没有旧托架、面板或把手附加几何。

## 夹持与初始平衡

硬盘是 `g_base` 的无关节子刚体，处于腕部传感器下游。盘长轴沿夹爪局部 Z、厚度沿局部 Y；机械臂从后端 106 mm 短边的中间持盘，夹爪朝向与插入方向同为世界 +X。硬盘后端面位于夹爪局部 Z=0.125 m，中心位于 Z=0.2135 m；pinch 参考点在后端面向内 20 mm、宽度中线上，指垫在上下表面形成实际接触区域。

两指由原 2F-85 四连杆几何求解，平行指垫内表面相距 26 mm。理想抓持使用 `grasp_lock_*` 等式约束固定八个指关节；原连杆约束与夹爪执行器保留。连接杆角度允许小的正值以容纳此闭合几何。该设定用于隔离插口接触问题，不是对真实夹爪抓取能力的验证。

仅排除硬盘和指机构内部的碰撞；插口与盘、插口与夹爪和机械臂均保留碰撞。硬盘与手指不靠摩擦持稳，发送张爪命令不会释放硬盘。

`home` 保存几何关节位置与静态重力平衡控制量；二者不是同一个数组。普通位置命令仍保持原适配器语义，不隐式做重力补偿。展示入口直接保持 keyframe 控制量；测力验证入口显式叠加位置伺服的重力/偏置力前馈。

## 接触与传感器

- 硬盘与插口：摩擦系数参数 `0.3 0.005 0.0001`，`solref="0.002 1"`、`solimp="0.99 0.999 0.0001"`，接触 margin=0，不通过增大间隙获得通过。
- 时间步 0.001 s，implicitfast 积分，椭圆摩擦锥，求解上限 100 次，tolerance=1e-10；验收另运行 0.0005 s。
- 力信号为 `wrist_force`、`wrist_torque`，在 `wrist_ft_site` 表达，顺序 `[Fx,Fy,Fz,Tx,Ty,Tz]`。
- 此模型中传感器的父对下载荷方向与环境施加到硬盘上的接触载荷相反。验证将接触力和力矩平移到腕部原点后比较，不能仅比较向量模长。
- 原始信号包含工具与负载重力。`tare()` 只扣除当前姿态静态基线，不含通用重力补偿、噪声、滤波或标定矩阵。

质量、惯性分布、摩擦、接触刚度与固定插口都是实验假设。0.25 mm 间隙是实际碰撞几何间隙，不能将软接触穿透误认为额外允许公差。
