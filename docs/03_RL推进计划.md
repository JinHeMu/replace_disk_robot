# RL 推进计划

## 目标与现状

JAKA ZU5 将已夹持硬盘送入固定机架导轨；用户已确认手柄可稳定完成插入。
任务从入口附近开始，先人工复位；成功定义为正确入轨并达到实测目标插深。

现有基础是手柄/键盘、导纳执行链、JAKA 仿真和控制日志，学习依赖已安装。
D435 目前只有独立取流检查；同步示教、JAKA Gym 环境、成功标签和在线训练仍需开发。
`rl/` 现有代码是 UR5e 残差/CEM 演示，不是 JAKA 的 SAC 训练器。

## 推荐路线

**先采集视觉示教，建立 BC 基线，再做示教与人工接管辅助的 SAC。**
沿用现有导纳执行链；残差 RL 留作后续对照，不先堆接触状态机。

```text
D435 图像 + TCP 状态 + 六维力 + 执行状态
                    ↓
       任务策略 / 手柄接管（选择一个）
                    ↓
    名义运动 → 现有导纳 → Servo → 限力 → JAKA
```

| 阶段 | 要完成的工作 |
| --- | --- |
| 1. 同步示教 | 固定 D435 视角，采集 RGB-D 与控制日志；记录 episode、成功/失败和复位边界，先收集约 30–50 条示教 |
| 2. 统一接口 | 共用人/策略动作接口，接入观测、动作仲裁和 `reset/step`；先在 JAKA 仿真核对坐标与切换行为 |
| 3. BC 基线 | 用图像和数值状态模仿手柄名义动作，记录独立试验的自主成功率 |
| 4. 人在环 RL | 示教与在线数据共同训练 SAC；记录实际接管动作，定期冻结策略进行无接管评估 |
| 5. 残差对照 | 当 BC 已有稳定动作趋势时，比较“冻结 BC + RL 修正”与直接任务策略 |

## 第一版接口

- **视觉**：D435 固定观察入口，先以 640×480、30 fps 采集 RGB-D；策略先用 RGB 裁剪，深度保留。
- **观测**：图像、TCP 位姿/速度、补偿后的六维力及短时历史、名义跟踪误差、导纳偏移/速度和上一动作。
- **动作**：有界的六维末端名义速度，尺度依据成功示教；先不学习关节力矩或导纳参数。
- **坐标**：定义导轨入口任务系，+Z 指向内部；在接口处转换到现有线速度基座系、角速度 TCP 局部系约定，保留力矩参考点。
- **频率**：策略先从 10 Hz 验证，现有执行环保持 125 Hz；采图、训练和落盘不阻塞控制。
- **奖励**：以正确入轨的成功标签为主，可加时间和过大接触代价；插深按真实几何确定。

示教动作标签取**导纳前的名义指令**。保存图像/控制时间戳、仲裁后的实际动作、动作来源、
实际持续时间、下一观测和终止原因；观测只能使用当时已到达的图像。原始日志保留全部采样。

切换接管和零动作时复用现有回中重锚定语义，避免继续追赶旧目标；区分终止、超时和复位。
数据按完整 episode 划分训练与评估；人工接管完成的试验单独统计。

## 开发位置与评估

相机读取放在 `adapters`，拟新增 `applications/jaka_learning` 复用 `common` 执行链，
数据转换、训练和评估放在 `rl/`。完整 JAKA 硬盘—导轨训练场景尚待建立。

评估记录自主成功次数/总次数、接管次数、用时、峰值力/力矩和保护触发；BC、SAC、残差使用相同起点条件。
残差总动作必须能停止和退出，不能只允许在持续推进基线上做微小修正。

近期先完成：**D435 同步采集 + episode 标记 + 共用任务动作接口**。
参考：[HIL-SERL](https://hil-serl.github.io/)（示教与接管）、[ResiP](https://residual-assembly.github.io/)（残差结构）、[FORGE](https://noseworm.github.io/forge/)（后续仿真迁移）。
