# 环境配置

适用 Ubuntu 22.04/24.04 x86_64；本机已在 Ubuntu 22.04、RTX 3050 Ti 上验证软件环境。
所有命令在仓库根目录的 Bash 终端执行。

## 安装与激活

```bash
bash scripts/setup_env.sh && source scripts/activate_env.sh
```

安装内容：Python 3.12、JAKA SDK 依赖、MuJoCo、Pinocchio、Pygame、D435 SDK、
OpenCV、HDF5、PyTorch CUDA、Gymnasium、Stable-Baselines3 SAC 和 TensorBoard。
首次下载含 CUDA 运行库，系统库和相机 USB 权限安装需要 sudo 密码。

依赖统一记录在 `pyproject.toml` 和 `uv.lock`；Python 版本见 `.python-version`。
环境位于 `.venv/`，安装工具和缓存在 `.tools/`。重复安装命令即可按锁文件同步。
没有 sudo 时可用 `bash scripts/setup_env.sh --skip-system`，系统库和 USB 权限留待补齐。

后续每个新终端：

```bash
source scripts/activate_env.sh
```

该入口隔离 ROS 和系统 Python 的库路径。VS Code 解释器选择 `.venv/bin/python`。

## 检查

```bash
# JAKA SDK / 仿真、CUDA 运算、短 SAC 训练与保存加载
python examples/check_environment.py --require-cuda

# D435 接 USB 3，首次安装权限后重新插拔，再检查 RGB-D
python examples/check_environment.py --camera
```

无 GPU 时去掉 `--require-cuda`。相机检查读取 30 对 640×480 RGB-D，深度对齐到 RGB；
多台相机用 `--serial 序列号` 选择。OpenCV 为 headless 版本，不提供 `cv2.imshow`。
软件自检使用 Pendulum 验证 SAC，不连接机械臂；真实插入训练见 [RL 推进计划](03_RL推进计划.md)。
