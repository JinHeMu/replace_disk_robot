# 后续算法开发路线

## 当前基础

已提供单盘、单口、理想已夹持初始化，六维力读数，通用 FK/Jacobian/IK、规划工具和限力门。轴向/侧向接触验证只证明力信号链可用于后续实验；当前没有闭环力控插入。

## 下一条主链

1. 力处理：明确工具重力补偿、滤波、零偏更新、腕部到任务坐标系的 wrench 变换。
2. 接触控制：在 `contact` 实现受限导纳或力位混合控制，接口面向核心合同，不直接写 MuJoCo 状态。
3. 插入实验：从当前 init 出发，依次完成接近、入口接触与修正、推进；目标前端插深 50 mm。无后挡板，不能把轴向碰底作为成功判据。
4. 验收：定义插深、横向/角度误差、力/力矩、持续时间、超时和退回条件，测试不同初始误差与接触参数。

默认仍使用已知插口位置和理想抓持。摩擦夹持、打滑、视觉、RL、完整换盘流程和实机接入均属于独立后续工作，不隐含在本次场景重建中。
